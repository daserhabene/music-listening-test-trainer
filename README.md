# Music Listening Test Trainer - 듣기 시험 트레이너

서양음악사 감상시험 대비용 웹앱입니다. 곡을 랜덤으로 듣고 작곡가와 곡 제목을 맞히거나, 학습 모드에서 암기 포인트를 확인하며 외울 수 있습니다.

## 무엇을 하는 앱인가

- 로컬 `playlist.js` 파일을 불러와 감상시험 목록을 구성합니다.
- MP3 파일 또는 YouTube 링크를 재생합니다.
- `start`와 `end` 구간만 재생해 시험처럼 연습합니다.
- 작곡가와 곡 제목을 입력해 정답을 확인합니다.
- 오타와 별칭을 어느 정도 허용합니다.
- 연습, 학습, 시험, 오답 복습 모드를 지원합니다.
- 곡별 암기 메모를 브라우저에 자동 저장합니다.

## 사용 방법

1. `index.html`을 브라우저에서 엽니다.
2. `플레이리스트 불러오기`로 원하는 `.js` 플레이리스트를 선택합니다.
3. 상단 모드 버튼에서 `연습 모드`, `학습 모드`, `시험 모드` 중 하나를 선택합니다.
4. 필요하면 `메모하기` 또는 `전체 메모 보기`를 열어 암기 포인트를 적습니다.

## 파일 구조

```text
music-listening-test-trainer/
├── index.html
├── playlist_2026musichistory3_midterm.js
├── playlist_2026musichistory3_final.js
└── audio/
    ├── ...
    └── musichistory3_final/
        ├── ...
        └── list.txt
```

`audio/`는 로컬 음원 폴더입니다. 큰 오디오 파일은 GitHub에 올리지 않는 것을 권장합니다.

## 플레이리스트 형식

플레이리스트는 전역 `playlist = [...]` 형식의 JavaScript 파일입니다.

```javascript
playlist = [
  {
    composer: "베토벤",
    title: "피아노 협주곡 5번 황제 1악장",
    aliases: ["황제", "황제 1악장", "피아노 협주곡 5번"],
    file: "audio/beethoven_emperor.mp3",
    start: 0,
    end: 60
  }
];
```

## 필드 설명

| 필드 | 설명 |
| --- | --- |
| `composer` | 대표 작곡가 정답 |
| `title` | 대표 곡 제목 정답 |
| `aliases` | 허용할 별칭 목록 |
| `file` | 로컬 오디오 파일 경로 |
| `youtube` | YouTube URL 또는 embed URL |
| `start` | 재생 시작 초 |
| `end` | 재생 종료 초 |

`file`과 `youtube` 중 하나를 쓰면 됩니다. 둘 다 있으면 현재 앱은 `youtube`를 우선합니다.

## 모드

### 연습 모드

- 전체 곡을 랜덤 비복원 방식으로 출제합니다.
- 한 바퀴가 끝나면 자동으로 다음 회독을 시작합니다.
- 정답 확인 후 바로 정답 여부와 정답을 보여줍니다.
- 힌트와 정답률 통계를 볼 수 있습니다.

### 학습 모드

- 입력칸 없이 곡을 듣고 스스로 아는지 판단합니다.
- `정답 보기`로 작곡가와 제목을 확인할 수 있습니다.
- `아는 곡` 또는 `모르는 곡`을 반드시 선택해야 다음 곡으로 넘어갑니다.
- `모르는 곡`은 오답 목록에 들어갑니다.

### 시험 모드

- 전체 곡을 랜덤 비복원 방식으로 1회 출제합니다.
- 시험 중에는 정답, 힌트, 통계, 메모를 숨깁니다.
- 각 답안은 기록만 되고 정답은 공개되지 않습니다.
- 마지막 문제 후 점수와 틀린 곡 목록을 보여줍니다.

### 오답 복습

- `전체 오답 다시`: 누적 약점 목록으로 복습합니다.
- `이번 회독 오답 다시`: 현재 회독에서 틀린 곡만 복습합니다.

## 채점 방식

- 작곡가와 제목 모두 입력해야 합니다.
- 문자열을 정규화한 뒤 Levenshtein 유사도로 비교합니다.
- 작곡가와 제목 점수가 각각 `0.7` 이상이면 정답입니다.
- 제목은 `title`과 `aliases` 중 가장 높은 점수를 사용합니다.
- 제목에 번호, 악장, 곡 번호가 있으면 숫자 일치 여부도 확인합니다.

## 메모 기능

- `메모하기`: 현재 곡의 암기 메모를 씁니다.
- `전체 메모 보기`: 플레이리스트 전체 곡의 메모를 한 번에 보고 수정합니다.
- 메모 패널과 전체 메모 패널은 상단을 잡고 이동할 수 있습니다.
- 패널 오른쪽 아래를 잡아 크기를 조정할 수 있습니다.
- 시험 모드와 시험 종료 화면에서는 메모가 숨겨집니다.

메모는 브라우저 `localStorage`에 자동 저장됩니다.

```javascript
const key = `${song.composer}::${song.title}::${song.file || song.youtube || ""}`;
```

주의:

- 같은 브라우저에서는 유지됩니다.
- 브라우저 사이트 데이터나 캐시를 지우면 사라질 수 있습니다.
- 다른 브라우저나 기기와 자동 동기화되지는 않습니다.

## 통계

- 이번 회독 통계
- 전체 누적 통계
- 곡별 정답률과 `correct/total`을 표시합니다.
- 시험 모드에서는 숨겨집니다.

## 테마

- 라이트 모드와 다크 모드를 지원합니다.
- 배경색을 직접 고를 수 있습니다.
- 선택값은 `localStorage`에 저장됩니다.
